# Tableau Dashboard Build Guide

This guide walks you through building the "real-time" pandemic response dashboard referenced in
the project brief, using the CSVs generated in `data/`. Screenshots aren't included since you'll
be building this live in Tableau Desktop/Public on your Mac, but every step below is exact.

## 0. Connect to your data

1. Open Tableau Desktop (or Tableau Public).
2. **Connect → Text File** (or **More… → SQLite** if you have the SQLite ODBC driver installed)
   and select `data/rtpcr_tests.csv`.
3. Add the other CSVs as additional connections in the same data source:
   `hospitalizations.csv`, `resource_utilization.csv`, `facilities.csv`, `regions.csv`, `patients.csv`.
4. Build relationships (Tableau's default in recent versions) on:
   - `rtpcr_tests.patient_id` ↔ `patients.patient_id`
   - `patients.region_id` ↔ `regions.region_id`
   - `hospitalizations.patient_id` ↔ `patients.patient_id`
   - `hospitalizations.facility_id` ↔ `facilities.facility_id`
   - `resource_utilization.facility_id` ↔ `facilities.facility_id`

## 1. Sheet: RT-PCR Positivity Trend

- Drag `test_date` to Columns → set to **continuous day** (or week, for a smoother view).
- Create the calculated field `7-Day Rolling Positivity %` (see `calculated_fields.md`) and drag
  it to Rows.
- Add `result` to Filter, or better, use the pre-built calc `Is Positive` for the numerator.
- Chart type: **Line**. Add a reference line at whatever your local/regional alert threshold is
  (e.g. 5% or 10%) using Analytics → Reference Line.

## 2. Sheet: Hospitalization Funnel

- Rows: a set of calculated fields — `Positive Tests`, `Hospitalizations`, `ICU Admissions`,
  `Ventilator Cases` (see calculated_fields.md).
- Chart type: **Funnel** (via a bar chart sorted descending, or Tableau's funnel chart type in
  newer versions).
- This visualizes conversion rate at each stage of severity, directly supporting the "trend
  analysis on RT-PCR test results and hospitalization patterns" claim.

## 3. Sheet: Regional Heatmap

- Columns: `region_name`. Rows: `test_date` (truncated to Month).
- Color: `7-Day Rolling Positivity %`.
- Mark type: **Square** (heatmap grid) or use a filled map if you have geocoded region shapes.

## 4. Sheet: Resource Strain Gauge

- One sheet per resource type (ICU, beds, ventilators). For ICU:
- Columns: `facility_name`. Rows: `ICU Strain Index` (calculated field, see below).
- Chart type: **Bar**, colored red/yellow/green using a calculated field bucketing strain into
  `< 0.7 Normal`, `0.7–0.85 Elevated`, `> 0.85 Surge Warning`.
- Add `snapshot_date` as a filter with a **relative date** filter (e.g., "last 7 days") so the
  dashboard behaves like a live operational view.

## 5. Sheet: Resource Allocation Recommendation

- Connect a 6th data source: `data/analysis_outputs/icu_reallocation_plan.csv` (generated by
  `python/resource_optimization.py`).
- Table or bar chart: `facility_name` vs `recommended_bed_transfer`, colored by sign
  (positive = receiving beds, negative = donating beds).
- This sheet is what turns "we built dashboards that optimized resource allocation" from a
  claim into something you can literally click through in an interview.

## 6. Assemble the Dashboard

1. **Dashboard → New Dashboard**, size "Automatic" or a fixed 1600×900.
2. Drag in: Positivity Trend (top-left, large), Hospitalization Funnel (top-right),
   Resource Strain Gauge (bottom-left), Regional Heatmap (bottom-right), Reallocation
   Recommendation (bottom strip).
3. Add a **Date Range filter** (apply to all sheets using this data source) so the whole
   dashboard can be scrubbed through the pandemic timeline — this is what makes it feel
   "real-time" even though the underlying refresh is on a fixed CSV/DB extract.
4. Add a title, e.g. "COVID-19 Regional Healthcare Impact & Resource Allocation Dashboard".
5. **File → Save As** → save as a `.twbx` packaged workbook so the CSV data travels with the
   file (useful if you want to share this from your portfolio without also sharing raw CSVs).

## 7. Publishing (optional, for a portfolio link)

- **Server → Publish to Tableau Public** (free) gives you a shareable URL to put in your resume
  or portfolio next to this GitHub repo.
